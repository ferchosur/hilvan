# Orquestador de agentes de IA

Espacio de trabajo para diseñar un producto que permita coordinar herramientas y cuentas de IA para trabajar en proyectos compartidos.

El nombre es provisional; no es el nombre de producto.

## Método de trabajo: SDD

Usaremos desarrollo guiado por especificaciones (Spec-Driven Development):

1. **Requisitos:** definir problema, usuarios, alcance, reglas de negocio y criterios de aceptación.
2. **Diseño:** decidir arquitectura e interfaces que satisfacen los requisitos aprobados.
3. **Plan:** dividir el diseño en unidades implementables y verificables.
4. **Implementación:** desarrollar contra la especificación aprobada.
5. **Verificación:** comprobar cada criterio de aceptación y registrar resultados y desviaciones.

Una especificación en estado `draft` expresa hipótesis y decisiones pendientes. No autoriza por sí sola a implementar. Antes de implementar una capacidad, sus requisitos y criterios de aceptación deben estar acordados.
